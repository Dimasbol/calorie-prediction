# Предсказание калорийности блюд

Учебный проект по глубокому обучению. По фотографии блюда и списку ингредиентов
нужно предсказать общую калорийность порции. Целевая метрика — MAE меньше 50 ккал
на тестовой выборке.

В текущей версии выполнены анализ данных и сравнение простых моделей.
Результаты обучения нейросети и итоговая оценка на test пока не получены.

## Данные

[Датасет задания](https://disk.yandex.ru/d/kz9g5msVqtahiw) содержит 3 262 блюда
и справочник из 555 ингредиентов. Для каждого блюда есть фотография, состав,
масса порции и калорийность.

Официальное разбиение: 2 755 блюд в train и 507 в test. Из train выделена
валидационная часть; в результате для обучения осталось 2 204 блюда, для
валидации — 551. Seed разбиения — 42.

Перед обучением ID ингредиентов заменяются названиями из справочника.
Все используемые фотографии имеют размер 640×480. Пропуски в исходных таблицах
и точные повторы фотографий не обнаружены. Есть два нулевых значения калорийности
и отдельные большие значения — до 3 943 ккал. Они сохранены в выборке,
поскольку одной величины target недостаточно, чтобы признать наблюдение ошибочным.

Исходные данные хранятся в `data/` и не загружаются в Git:

- `data/dish.csv` — таблица блюд;
- `data/ingredients.csv` — справочник ингредиентов;
- `data/images/<dish_id>/rgb.png` — фотография блюда.

## Решение

Для изображения используется предобученная ResNet18, для названий ингредиентов —
DistilBERT. Признаки двух моделей объединяются и передаются в небольшую полносвязную
сеть. Последний слой имеет один выход без функции активации.

Функция потерь — L1. Основная метрика — MAE в ккал; дополнительно рассчитываются
RMSE и R². Масса порции не подается в основную модель, так как по условию на вход
поступают только фотография и ингредиенты.

При аугментации фотография сохраняется целиком. Используются отражение,
повороты на 90° и небольшие изменения цвета. Сильную обрезку не применяю:
она может удалить часть еды, хотя целевая калорийность останется прежней.

Параметры для RTX 4060 Ti: размер изображения 224×224, batch size 4,
накопление градиентов за 4 батча и смешанная точность. Первые две эпохи обучаются
новые слои, затем размораживаются ResNet18 и последние два блока DistilBERT.
Лучшая эпоха выбирается по MAE на валидации. Test при подборе не используется.

## Результаты

| Модель | MAE на validation, ккал | MAE на test, ккал |
|---|---:|---:|
| Медиана обучающей выборки | 164,04 | — |
| TF-IDF + Ridge, alpha=1 | 93,73 | — |
| ResNet18 + DistilBERT | 42,67 | 49,74 |

Текстовый baseline заметно лучше постоянного прогноза. Значит, названия ингредиентов
полезны для задачи, но ошибка пока выше требуемой. Следующий эксперимент проверяет,
улучшится ли оценка при добавлении фотографии.

Графики и таблицы EDA находятся в `reports/eda/`, ход работы — в `notebook.ipynb`.
Финальный checkpoint появится после обучения в `artifacts/main/best.pt`.

## Запуск

Окружение: Python 3.12, PyTorch 2.10.0 и torchvision 0.25.0 с CUDA 12.6.
Из корня проекта в PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install torch==2.10.0 torchvision==0.25.0 --index-url https://download.pytorch.org/whl/cu126
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m ipykernel install --user --name calories-gpu --display-name "Python 3.12 (calories GPU)"
.\.venv\Scripts\python.exe -m scripts.check_environment
.\.venv\Scripts\python.exe -m scripts.download_data
```

После установки открыть `notebook.ipynb`, выбрать созданное ядро и выполнить
ячейки по порядку. Обучение вызывается одной функцией:

```python
from scripts.utils import train
result = train("configs/main.yaml")
```

Для продолжения с последней сохраненной эпохи используется `resume=True`.
Проверка кода: `python -m pytest -q`.

## Ограничения

Список ингредиентов не содержит их количества. Одинаковый состав может соответствовать
порциям с разной калорийностью, а по одному снимку не всегда можно точно оценить объем.
Поэтому при анализе ошибок нужно учитывать размер порции, редкие продукты и смешанные блюда.
